</p>

A lightweight, open-source web browser for Android, built as part of the Carson software projects.

## 🚧 Project status

CarsonBrowser is currently in the early development stage. The repository is being prepared for the first working Android browser build.

### Planned features

- 🌐 Web browsing
- 🔎 Address bar with web search
- ◀️ Back and ▶️ forward navigation
- 🔄 Reload
- 🏠 Customizable home page
- 🗂️ Multiple tabs
- 🔖 Bookmarks
- 📜 Browsing history
- 📥 Downloads
- 🕵️ Private browsing
- 🌙 Dark mode
- ⚙️ Browser settings
- 📱 Android share and link-handling integration

More features will be added as development continues.

## 🛠️ Technology

The initial version is planned as a native Android application using Kotlin, AndroidX, and Android's WebView/Chromium-based web platform.

The project may evolve to use a different browser engine or additional components in future versions.

## 📱 Goal

The goal of CarsonBrowser is to create a simple, customizable Android browser that can grow into a full-featured browser over time.
